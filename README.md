## About the Subject

AOOPS builds on core object oriented programming and takes it towards designing
real systems. The focus is less on syntax and more on how objects, types and
abstractions are composed so that a program stays correct and extensible as it grows.

Topics covered across the subject include:

- Classes, objects, constructors and the object lifecycle
- Encapsulation, abstraction, inheritance and polymorphism
- Interfaces, abstract classes and composition over inheritance
- Value objects, immutability and domain modelling
- Generics and type safety
- Collections framework and iteration
- Exception handling and designing for failure
- Records, sealed types and modern Java language features
- SOLID principles and common design patterns
- Multithreading, concurrency and streams
- Applying OOP design to end to end system / project work

All code in this repository is written in **Java**.
